# 우리집 가계부 — 리눅스판 · 윈도우판

윈도우용 **우리집 가계부 v5.75**(2009, VB6)를 분석해서, 같은 기능을 Kubuntu에서 바로 도는 프로그램으로 새로 만든 것입니다.
Wine·마이크로소프트 구성요소가 필요 없고, 윈도우에서 쓰던 자료(`data` 폴더의 `.mdb`)를 그대로 가져올 수 있습니다.
1.1.1부터 같은 소스로 **윈도우판**(설치 프로그램·휴대용 zip)도 만듭니다 (아래 1-1).

- 만든 방식: Python 3 + PyQt6(KDE와 같은 Qt) + SQLite
- 원본 코드를 옮긴 것이 아니라, 원본의 **자료 구조·도움말·화면**을 분석해 같은 동작을 새로 구현했습니다.
- 처음 암호·암호 설정법·사용법은 **`사용가이드.txt`** 에 정리했습니다 (윈도우 메모장에서도 바로 열림).

## 1. 설치 (리눅스)

설치 방법은 세 가지이며 **하나만** 쓰세요. 쿠분투에서는 ①이 가장 편합니다.

| 방법 | 파일 | 설치 | 제거 (데이터는 남음) |
|---|---|---|---|
| ① deb 패키지 (쿠분투·우분투·데비안) | `gagyebu-linux_1.8.0_all.deb` | `sudo apt install ./gagyebu-linux_1.8.0_all.deb` | `sudo apt remove gagyebu-linux` |
| ② rpm 패키지 (페도라 계열) | `gagyebu-linux-1.8.0-1.noarch.rpm` | `sudo dnf install ./gagyebu-linux-1.8.0-1.noarch.rpm` | `sudo dnf remove gagyebu-linux` |
| ③ 설치 스크립트 (sudo 없이 내 계정에만) | `gagyebu-linux.tar.gz` | `./install.sh` (sudo 붙이지 말 것) | `./uninstall.sh` |

- ①·② 는 필요한 패키지(`python3-pyqt6` 등)를 apt/dnf 가 함께 설치합니다. 파일 이름 앞의 `./` 를 꼭 붙이세요 (없으면 인터넷 저장소에서 찾음).
- 지운 뒤 다시 설치할 때는 같은 설치 명령을 다시 실행하면 됩니다. 새 버전 deb/rpm 도 같은 명령으로 덮어 설치(업그레이드)됩니다.
- 설치된 상태에서 같은 버전을 다시 깔고 싶으면(파일이 망가졌을 때 등) `sudo apt reinstall ./gagyebu-linux_1.8.0_all.deb`
- **③으로 설치한 적이 있으면 ①·②를 쓰기 전에 `./uninstall.sh` 를 먼저 실행하세요.** 남아 있으면 내 계정의 예전 실행 파일·메뉴 항목(`~/.local/bin/gagyebu`, `~/.local/share/applications/gagyebu-linux.desktop`)이 패키지보다 먼저 잡힙니다.
- 앱 메뉴 → **사무 → 우리집 가계부 (리눅스판)**, 또는 터미널에서 `gagyebu`
- 데이터 파일: `~/.local/share/gagyebu/gagyebu.sqlite3` — 프로그램을 지우거나 다시 설치해도 남고, 다시 설치하면 그대로 이어서 씁니다.
- ③ 방식 상세:
  ```bash
  tar xzf gagyebu-linux.tar.gz
  cd gagyebu-linux
  ./install.sh                                    # python3-pyqt6 등 설치에 sudo 비밀번호를 물어봄
  ./install.sh --import-data ~/윈도우자료/data     # 윈도우 자료까지 한 번에 가져오기
  ./uninstall.sh --purge                          # 데이터도 삭제 (먼저 홈 폴더에 사본 생성)
  ```

## 1-1. 설치 (윈도우 10/11, 64비트)

| 방법 | 파일 | 하는 법 |
|---|---|---|
| 설치 프로그램 | `우리집가계부-윈도우판-1.8.0-setup.exe` (GitHub 릴리스: `gagyebu-windows-1.8.0-setup.exe`) | 실행 → (파란 "Windows의 PC 보호" 창이면 [추가 정보] → [실행]) → [다음] → [설치]. 관리자 권한 필요 없음 |
| 휴대용 | `우리집가계부-윈도우판-1.8.0-휴대용.zip` (GitHub 릴리스: `gagyebu-windows-1.8.0-portable.zip`) | 압축을 풀고 `우리집가계부.exe` 실행 |

- 설치 위치 `%LOCALAPPDATA%\Programs\Gagyebu`, 바탕화면·시작 메뉴에 **우리집 가계부 (새 버전)** — 예전 프로그램과 따로 설치되고 예전 자료는 건드리지 않습니다.
- 데이터 파일 `%APPDATA%\gagyebu\gagyebu.sqlite3`. 제거해도 남습니다. 리눅스판과 같은 형식이라 백업 파일로 서로 옮길 수 있습니다.
- 제거: 윈도우 설정 → 앱 → "우리집 가계부 (윈도우판 새 버전)" (또는 시작 메뉴 → 우리집 가계부 → 제거)
- 구성: 파이썬 3.12(python.org 임베디드 배포판, 파이썬 재단 서명 확인) + PyQt6 6.11(필요한 모듈만) + 윈도우용으로 다시 빌드한 mdbtools(예전 .mdb 읽기) + 실행기
- 만들기(우분투에서): `packaging/windows/build-windows.sh <python-3.12.x-embed-amd64.zip>`
  → `dist-windows/` 에 setup.exe 와 휴대용 zip (mingw-w64, nsis, win-iconv-mingw-w64-dev 필요)

## 2. 윈도우에서 쓰던 자료 옮기기

윈도우의 `우리집 가계부\data` 폴더를 **통째로** USB 등에 복사해 오세요. 위치는 둘 중 하나입니다.

| 위치 | 설명 |
|---|---|
| `C:\Users\<사용자>\AppData\Local\VirtualStore\Program Files (x86)\우리집 가계부\data` | 윈도우 7 이후 관리자 권한 없이 쓰면 저장 내용이 여기로 갑니다. **이 폴더가 있으면 이쪽이 최신** |
| `C:\Program Files (x86)\우리집 가계부\data` | 기본 설치 위치 (32비트 윈도우는 `Program Files`) |

가져오기 방법: 프로그램의 **설정 → 자료 가져오기**, 또는 터미널에서 `gagyebu --import-from <폴더>` (③ 방식은 설치할 때 `--import-data <폴더>` 도 가능).
가져오면 지금 데이터를 대신하며, 이전 데이터는 `~/.local/share/gagyebu/auto-backup/`에 자동 보관됩니다. 원본 `.mdb`는 읽기만 합니다.
시작 암호는 원본에서 쓰던 암호가 그대로 옮겨집니다 (원본에서 바꾼 적이 없다면 기본값 `1111`). 설정 → 암호 · 백업에서 바꾸거나 해제할 수 있습니다.
고정 수입·지출(원본의 '예약')은 원본에서 마지막으로 자동입력한 날까지 처리된 것으로 보고, 그 뒤 날짜만 입력할지 묻습니다.

## 3. 화면 꾸미기 — 미니홈피 테마 (1.1.0부터 기본)

아늑단 이미지를 바탕으로 2000년대 미니홈피 느낌으로 꾸민 화면입니다. **설정 → 화면 꾸미기**에서 바로 바꿀 수 있습니다.

| 부분 | 내용 |
|---|---|
| 바탕 | 스티커 시트의 청록색(#347C7C) + 물방울 점무늬 + 도트 반짝이 |
| 맨 위 줄 | `TODAY 오늘 지출 \| 이달 이번 달 지출` 계수기, ☆ 제목 ☆, 흐르는 전광판(잔액·이달 수입/지출·다짐). 마우스를 올리면 전광판이 멈춤 |
| 왼쪽 프로필 | 미니미(스티커 62개 중 고르기, 그림을 누르면 바뀜), TODAY IS..(오늘의 기분), 잔액·이달 수입/지출, 이번 달 다짐. ◀ 로 접기 |
| 오른쪽 탭 | 틀 오른쪽에 붙은 메뉴 탭 (가계부 ~ 설정) |
| 화면 제목 띠 | 화면마다 다른 스티커 + 한 줄 소개 |
| 단추·표·입력칸 | 검은 외곽선(스티커 선), 반짝이 단추, 하늘색 표 머리글, 분홍 이름표 묶음 상자 |
| 글꼴 | 도트 글꼴 갈무리11 (본문 12px, 제목 24px). 읽기 힘들면 "시스템 글꼴"로, 글자 크기는 1px 단위로 (아래 3-5) |
| 암호 창 | 눈 가린 고양이 + "쉿!" 한마디 |
| 아이콘 | 앱 메뉴·창 아이콘도 고양이로 |

- **처음 화면으로 되돌리기**: 설정 → 화면 꾸미기 → 테마 "기본"
- 꾸미기 설정은 데이터 파일이 아니라 `~/.config/gagyebu-linux/gagyebu.conf`에 저장되므로 자료를 가져오거나 복원해도 그대로입니다.
- 화면이 좁으면(1366x768 노트북 등) 프로필을 ◀ 로 접으면 가계부 화면이 넓어집니다.
- 스티커는 받은 시트 4장 중 투명 배경 2장에서 오려 냈습니다 (`gagyebu/assets/stickers`, 62개). 이름이 적힌 시트의 이름은 미니미 고르기 창의 말풍선에 "원본 표기"로 보입니다.

### 3-1. 피드·타임라인 테마 (1.2.0, 1.6.0부터 화면이 SNS 앱 모양)

화면 구성이 SNS 앱처럼 바뀌는 테마입니다. **기능은 그대로**이고 화면 모양만 다릅니다. 실제 서비스의 로고·이름은 쓰지 않았습니다.
피드·타임라인 모두 **미니홈피 색(기본) / 밝게 / 어둡게** 세 가지 색이 있습니다 (모두 6개).

| | 피드 (사진 SNS 모양) | 타임라인 (짧은 글 SNS 모양) |
|---|---|---|
| 왼쪽 줄 | 손글씨 로고 · 아이콘 메뉴 · [새 내역] · 가계부 고르기 · 내 프로필 | 고양이 로고 · 아이콘 메뉴 · [입력하기] 알약 단추 · 가계부 고르기 · 내 프로필 |
| 가계부 위쪽 | 프로필 머리 (큰 미니미 · 가계부 이름 · 이달 수입/지출/차액 · 기분·다짐·오늘 지출·잔액) | 맨 위에 붙은 탭 [10월 · 전체 기간 · 정렬] + 고정된 글 (이달 요약) |
| 동그라미·순위 | [＋새 내역] + 지출 많은 카테고리 동그라미 (누르면 그 카테고리 검색) | 오른쪽 '많이 쓴 곳' 순위 (누르면 그 카테고리 검색) |
| 목록 | 하루 = 게시물 한 개: 사진 칸(그날 금액·옛날 디카 날짜 도장·고양이) · ♥(수입 있는 날) 💬(이 날 새 내역) ⇅(순서) 📅(달력에서 보기) · ⋯ 메뉴 · 내역은 게시물 글처럼 | 한 건 = 글 한 개: 내용 @카테고리 · 날짜 · 메모 · 금액 · 💬(수정) 🔁(같은 내용 다시 입력) ♥ 📊(잔액) |
| 오른쪽 | 입력하기 | 많이 쓴 곳 + 입력하기 |

- 탭: [10월] [전체 기간] [최근 것 위로/오래된 것 위로] — 예전의 '전체 기간'·'최근 것을 위로' 칸과 같습니다.
- **🔁 다시 입력**: 그 내역을 오늘 날짜의 새 내역으로 입력 칸에 채웁니다 (고친 뒤 저장, 원래 내역은 그대로).
- 목록에서 한 줄 고르기·여러 줄 골라 삭제·Delete 키·CSV·인쇄는 표 모양일 때와 똑같습니다. 가운데 칸은 위쪽 덩어리와 목록이 함께 스크롤됩니다.
- 화면 구성 순서를 따로 정하지 않았으면 피드는 프로필 머리가, 타임라인은 달 이동 → 고정된 글이 위에 옵니다.

| 색 | 바탕 | 포인트 |
|---|---|---|
| 미니홈피 색 | 청록 바탕(물방울 점) + 흰 카드, 맨 위 제목·메뉴는 흰 글자 | 피드 분홍, 타임라인 청록 (동그라미 테두리는 하늘·분홍·노랑) |
| 밝게 | 흰 바탕 | 피드 분홍, 타임라인 파랑 |
| 어둡게 | 검은 바탕 | 피드 분홍, 타임라인 파랑 |

- 1.3.0까지의 '피드'·'타임라인(밝게)'는 지금의 '피드 · 밝게'·'타임라인 · 밝게'와 같습니다. 1.4.0에서 '피드'·'타임라인'은 미니홈피 색으로 바뀌었으니, 예전 흰 화면이 좋으면 '밝게'를 고르세요.

- 글꼴은 시스템 글꼴입니다 (설정에서 고운돋움 등 추가 글꼴을 고르면 그 글꼴).
- 달력·그래프·통계의 글자색도 어두운 테마에 맞춰 바뀝니다.

### 3-2. 순서 바꾸기 · 색 바꾸기 (1.2.0)

순서 바꾸기 창에서는 줄을 끌어다 놓거나 [맨 위로]·[위로 ▲]·[아래로 ▼]·[맨 아래로]로 옮긴 뒤 [저장]을 누릅니다.

| 무엇 | 어디서 | 어디에 저장 |
|---|---|---|
| 메뉴 순서 | 설정 → 화면 꾸미기 → [메뉴 순서 바꾸기…] | 이 PC (맨 위 메뉴 = 켰을 때 처음 화면) |
| 가계부 화면 구성·입력 상자 위치 | 설정 → 화면 꾸미기 → [화면 구성 순서…], 입력 상자 오른쪽/왼쪽 | 이 PC |
| 같은 날 내역 순서 | 가계부 화면에서 그날 내역을 고르고 [같은 날 순서…] | 자료 파일 → 안드로이드판에서도 같은 순서 |
| 카테고리·세부 카테고리 순서 | 설정 → 카테고리 → [순서 바꾸기…] | 자료 파일 |
| 주소록·일기장·메모장 순서 | 각 화면의 [순서 바꾸기…] | 자료 파일 |
| 테마 색 (포인트·바탕·카드·글자·수입·지출) | 설정 → 화면 꾸미기 → 이 테마의 색 | 이 PC (테마마다 따로) |

- **같은 날 내역 순서**: 잔액도 정한 순서로 계산합니다. '최근 것을 위로'에서도 정한 날은 그 순서 그대로입니다.
- **카테고리 순서**: 입력할 때 고르는 목록과 통계에 그대로 쓰입니다.
- **새로 추가한 것**: 주소록·일기·메모를 새로 추가하면 정해 둔 순서의 맨 아래에 붙습니다.
- **나머지 색**: 테두리·흐린 글자·선택 표시 같은 색은 고른 색으로 계산합니다. 달력·그래프 글자색도 따라 바뀝니다.
- **자료 파일 호환**: 표에 칸을 더하지 않았습니다.
  - 카테고리·같은 날 내역·주소록·일기 순서는 `meta` 표(`order_groups:<가계부>`, `order_day:<가계부>`, `order_list:contact|diary`)에 JSON으로 저장합니다.
  - 세부 카테고리·메모 순서는 원래 있던 `sort` 칸을 씁니다.
  - 그래서 예전 판으로 열어도 오류가 나지 않습니다.

### 3-3. 그래프 종류 · 연·월 바로 고르기 (1.3.0)

**그래프 종류**: 그래프 화면 위쪽의 [종류] 목록에서 고릅니다. 고른 종류는 이 PC에 기억해 두었다가 다음에 열 때도 그대로 씁니다.

| 종류 | 보여 주는 것 |
|---|---|
| 꺾은선 그래프 | 기간(달 또는 날)별 금액을 선으로 |
| 막대 그래프 | 기간마다 항목별 막대를 나란히 |
| 누적 막대 그래프 | 기간마다 항목 막대를 쌓음 — 막대 높이가 그 기간 합계 |
| 영역 그래프 | 꺾은선 아래를 옅게 칠함 |
| 누계 꺾은선 | 처음 달(날)부터 차례로 더해 간 금액. 오른쪽 범례의 금액은 마지막 누계 |
| 가로 막대 (항목별 합계) | 항목마다 기간 전체 합계를 큰 것부터 |
| 원 그래프 (비율) | 항목별 합계의 비율(%) |
| 도넛 그래프 (비율) | 원 그래프 + 가운데에 합계 금액 |

- 원·도넛은 합계가 0보다 큰 항목만 그립니다. 환불처럼 합계가 0 이하인 항목은 빼고, 그래프 아래에 몇 개를 뺐는지 적습니다.
- 음수가 조금만 있을 때(환불 등) 아래쪽 눈금을 한 칸 통째로 비우지 않도록 축을 줄였습니다.
- '월단위'의 달은 목록에서 바로 고릅니다. 연도는 칸에 바로 숫자를 쳐서 바꿀 수 있습니다.

**연·월 바로 고르기**: 가계부·달력·일기장·통계(월별·일별)·자산(카드) 화면의 `◀ 2026년 10월 ▼ ▶` 에서
가운데 글자를 누르면(또는 Tab 으로 옮겨 와 Enter) 연·월 고르기 창이 뜹니다.

- 연도는 창 안의 ◀▶ 로 넘기거나 칸에 바로 쳐서 바꾸고(1900~2100년), 달 단추를 누르면 그 달로 바로 갑니다.
- 지금 보고 있는 달은 강조색, 오늘이 있는 달은 굵은 밑줄로 표시합니다.
- [이번 달]은 오늘이 있는 달로, [닫기]는 바꾸지 않고 닫습니다. 바깥의 ◀▶ 한 달씩 이동과 [이번 달] 단추는 그대로 있습니다.

### 3-4. 업데이트 (1.4.0)

새 버전이 나오면 프로그램을 켤 때 알려 줍니다. GitHub 릴리스(이 저장소)를 확인합니다.

1. 켤 때 새 버전이 있으면 **업데이트 내용**을 간단히 보여 주고 "업데이트하시겠습니까?"를 묻습니다.
   - **아니요**: "설정 → 업데이트에서 언제든 직접 새 버전을 확인하고, 내려받아 설치할 수 있습니다"라고 알려 줍니다.
   - **예**: 설치 파일을 내려받습니다 (진행 막대, 취소 가능).
2. 다 받으면 "지금 설치할까요?"를 묻습니다.
   - **아니요**: 받은 파일을 기억해 두었다가 설정 → 업데이트의 [내려받은 새 버전 설치]로 나중에 설치합니다.
   - **예**: 설치합니다 (아래 표).

| 설치 방식 | 설치할 때 |
|---|---|
| 윈도우 설치 프로그램으로 설치 | 프로그램이 닫히고, 새 버전이 조용히 설치된 뒤 다시 열립니다 |
| deb·rpm 패키지 | 관리자 암호 창이 뜹니다. 설치가 끝나면 다시 열립니다 |
| 윈도우 휴대용 zip, 압축을 풀어 직접 설치 | 자동 설치가 되지 않아 내려받기 페이지를 엽니다 |

- **설정 → 업데이트**: 켤 때 자동 확인 켜기·끄기, [업데이트 확인], [새 버전 내려받기], [내려받은 새 버전 설치], 새 버전의 업데이트 내용.
- 새 버전 확인 때는 GitHub의 공개 릴리스 목록만 읽습니다. 가계부 자료는 어디에도 보내지 않습니다.
- 받은 설치 파일은 릴리스에 적힌 크기·SHA-256과 맞을 때만 설치합니다.
- 인터넷이 안 되면 켤 때는 조용히 넘어가고, [업데이트 확인]을 눌렀을 때만 알려 줍니다.
- 이 기능은 1.4.0부터 들어 있습니다. 1.3.0 이하에서 1.4.0으로는 예전처럼 직접 설치해야 합니다.

### 3-7. 표 보기 (1.6.1)

통계를 비롯한 모든 표(가계부·검색·자산·고정 수입·지출·설정·상세 내역)를 테마 8개에서 캡처해 점검하고 읽기 쉽게 고쳤습니다.

| 고친 곳 | 전 | 후 |
|---|---|---|
| 통계 폭 | 표가 왼쪽 절반만 차지, 오른쪽이 빔 | 금액 칸이 남는 폭을 나눠 가져 화면 폭을 다 채움 (일별처럼 칸이 많으면 가로 스크롤) |
| 0 원 | 칸마다 진한 0 | 흐린 회색 0 — 진짜 금액이 먼저 보임 |
| 카테고리 구분 | 얇은 선뿐 | 카테고리 칸을 옅은 색으로, 소계 줄 아래·합계 줄들 위에 굵은 선 |
| 칸 여백·줄 높이 | 금액이 칸 끝에 붙음, 줄 높이 24px | 칸 양옆 여백 + 줄 높이를 글자 크기에 맞춰(최소 26px) |
| 고른 줄 | 수입·지출 글자가 검정으로 | 고른 줄 색이 옅으면 수입·지출 색 그대로 (기본 테마처럼 진한 선택색이면 흰 글자) |
| 머리줄 (피드·타임라인) | 흰 바탕에 회색 글자 | 옅은 회색 바탕 + 진한 글자 + 아래 선 |

- 표 색은 미니홈피 색으로 통일: 미니홈피 테마와 미니홈피 색(피드·타임라인) 테마의 표가 같은 모양입니다 — 하늘색 띠 머리줄, 민트 줄무늬, 살구색 소계, 연보라 합계, 민트 카테고리 칸, 청록 선, 분홍 고른 줄 (안드로이드판과 같은 색). 밝게·어둡게 테마는 구조(줄무늬·소계·굵은 선)는 같고 색은 흰·검은 바탕에 맞춤(포인트 색을 옅게/어둡게). 테마 색을 바꾸면 표 색도 따라 바뀝니다.
- 인쇄·CSV 는 그대로입니다 (화면 그리기만 바뀜).

- 수입 카테고리(0번)는 지금처럼 지울 수 없습니다.

## 6. 분석 내용 요약

- 원본 DB: Access 97(Jet 3) `.mdb`, 글자는 CP949. 비밀번호가 걸려 있지만 `mdbtools`는 읽을 수 있음
- `main.mdb`: 장부 목록(`장부명`), 시작 암호(`가계부환경`), 일정·기념일(`memday`)·주소록(`address`)·일기(`ilgit`)·메모(`memot`)
- `home<파일명>.mdb`: 장부 하나. 기본 장부 "가계부 장부"는 `homemaster.mdb`. `내역`·`계정과목`·`계정분류`·`예산`·`myautoin`(예약)·`myautode`(예약 입력 기록)
- `asset.mdb`: `통장정보/거래`, `카드정보/거래`(할부는 회차별 행), `증권·보험·부동산 정보/거래`
- 계정코드 2자리 = 대분류 + 소분류, 대분류 `0` = 수입 (exe 안의 SQL `계정코드 like '0%'`로 확인)
- 원본의 자료가 있는 모든 표를 새 구조로 옮기는 것과 별도로 `legacy_raw` 표에 **원본 그대로도 보관** (옮기며 쓰지 않은 칸, 의미를 모르는 `단1~10`·`테이블1~10` 등도 잃지 않음)

## 8. 문제 해결

| 증상 | 조치 |
|---|---|
| `PyQt6 를 불러올 수 없습니다` | `sudo apt install python3-pyqt6` |
| 가져오기에서 `mdbtools 가 없습니다` | `sudo apt install mdbtools` |
| 암호를 잊음 | 백업 파일로 복원하거나, 윈도우 원본 자료를 다시 가져오면 원본 암호로 돌아감 |
| 고정 수입·지출 확인창에 지난 날짜가 나옴 | 이번 달 이전 것은 기본으로 체크하지 않습니다. 필요한 것만 체크해 입력하고, 필요 없는 것은 체크 후 "건너뛰기" — 다시 묻지 않음 |
| "이미 실행 중입니다" | 같은 데이터를 두 창에서 동시에 쓰지 않도록 막은 것입니다. 열린 창을 쓰세요 |
| 확인/취소 버튼이 영어 | `sudo apt install qt6-translations-l10n` (설치 스크립트가 함께 설치) |
| deb 설치 끝에 `N: Download is performed unsandboxed as root …` | 홈 폴더의 deb 파일을 apt 가 읽을 때 나오는 안내일 뿐, 설치는 정상입니다 |
| 도트 글꼴이 작거나 흐릿함 | 설정 → 화면 꾸미기 → 글꼴 "시스템 글꼴", 또는 글자 크기를 1px씩 키우기 |
| 꾸민 화면이 싫음 / 예전 화면이 좋음 | 설정 → 화면 꾸미기 → 테마 "기본" |
| 패키지로 설치했는데 예전 버전이 뜸 | ③ 방식으로 설치한 것이 남아 있는 경우: 압축을 푼 폴더에서 `./uninstall.sh` (또는 `rm ~/.local/bin/gagyebu ~/.local/share/applications/gagyebu-linux.desktop`) |
