# 우리집 가계부 — 안드로이드판 설치·사용 가이드 (1.2.0)

PC판(리눅스·윈도우)과 같은 자료 파일을 쓰는 안드로이드 앱입니다. 자료 파일을 주고받으면 PC에서 쓰던 장부를 휴대폰에서 이어 쓸 수 있고, 반대로도 됩니다.

## 1. 설치

| 순서 | 할 일 |
|---|---|
| 1 | `우리집가계부-안드로이드-1.2.0.apk` 파일을 휴대폰으로 옮깁니다 (USB, 카카오톡 '나에게 보내기', 구글 드라이브 등). GitHub 릴리스에서 받으면 이름이 `gagyebu-android-1.2.0.apk`입니다. |
| 2 | 휴대폰의 **내 파일**(또는 파일·다운로드) 앱에서 그 파일을 누릅니다. |
| 3 | "출처를 알 수 없는 앱" 안내가 나오면 **설정 → 이 출처 허용**을 켜고 돌아와 **설치**를 누릅니다. |
| 4 | Play 프로텍트가 "알 수 없는 개발자" 경고를 띄우면 **세부정보 → 그래도 설치**를 누릅니다. 플레이 스토어를 거치지 않은 앱이라 나오는 경고입니다. |

- **필요한 안드로이드 버전**: 7.0 이상
- **필요한 WebView**: 휴대폰의 'Android System WebView'(또는 Chrome)가 2019년 이후 버전이어야 합니다. 플레이 스토어가 보통 자동으로 업데이트합니다. 너무 오래되었으면 앱이 업데이트하라고 알려 줍니다.
- **권한**: 이 앱은 인터넷·저장소·연락처 권한을 쓰지 않습니다. 파일을 주고받을 때만 시스템 파일 선택 창을 엽니다.

## 2. 처음 실행

- 암호 없이 바로 열립니다. 장부는 **가계부 장부** 하나와 기본 계정과목으로 시작합니다. PC판 처음 상태와 같습니다.
- 아래 탭: **가계부 · 달력 · 결산 · 자산 · 더보기**
  - 더보기에는 검색·그래프·예약 입력·기념일·주소록·일기장·메모장·설정·도움말이 있습니다.
- 휴대폰의 **뒤로** 버튼은 열린 창 → 하위 화면 → 가계부 탭 순서로 닫고, 마지막에 앱을 끕니다.

## 2-1. 테마 (더보기 → 설정 → 화면 꾸미기)

| 테마 | 모양 |
|---|---|
| 미니홈피 (기본) | 2000년대 미니홈피 느낌, 아늑단 이미지, 도트 글꼴 |
| 기본 | 깔끔한 흰 화면 |
| 피드 (사진 SNS 느낌) | 흰 바탕·분홍 포인트. 가계부 맨 위에 이달 지출 많은 계정과목 동그라미, 하루 내역이 게시물 카드 하나 |
| 타임라인 (밝게·어둡게) | 흰/검은 바탕·파란 포인트. 날짜 띠 아래 내역 한 건이 짧은 글 한 개 |

- 피드·타임라인은 기능이 같고 모양만 다릅니다. 내역을 누르면 똑같이 수정 창이 뜹니다.
- 피드·타임라인은 휴대폰 기본 글꼴을 쓰고, 맨 위 상태 표시줄 색도 테마에 맞춥니다.
- 실제 SNS 서비스의 로고·이름은 쓰지 않았습니다.

## 2-2. 순서 바꾸기 · 색 바꾸기

순서 바꾸기 창에서는 줄 왼쪽의 **☰ 를 눌러 끌거나**, 오른쪽 **▲▼** 로 옮긴 뒤 **저장**을 누릅니다. **기본 순서로**를 누르면 처음 순서로 돌아갑니다.

| 무엇 | 어디서 | 어디에 저장 |
|---|---|---|
| 메뉴 순서 | 더보기 화면 오른쪽 위 **메뉴 순서**, 또는 설정 → 화면 꾸미기 | 이 휴대폰 (위 4개 = 아래 탭, 맨 위 = 처음 화면) |
| 가계부 화면 구성 | 가계부 화면 오른쪽 위 **☰**, 또는 설정 → 화면 꾸미기 | 이 휴대폰 |
| 같은 날 내역 순서 | 가계부 목록의 날짜 옆 **⇅** | 자료 파일 → PC판에서도 같은 순서 |
| 계정과목 순서 (대분류·소분류) | 설정 → 계정과목 → **대분류 순서 바꾸기** / 대분류 옆 **소분류 순서** | 자료 파일 → PC판에서도 같은 순서 |
| 주소록·일기장·메모장 순서 | 각 화면 오른쪽 위 **순서** | 자료 파일 → PC판에서도 같은 순서 |
| 테마 색 | 설정 → 화면 꾸미기 → **이 테마의 색** | 이 휴대폰 (테마마다 따로) |

- **같은 날 내역 순서**: 잔액도 정한 순서대로 계산됩니다. '최근 것을 위로'를 켜도, 순서를 정한 날은 정한 순서 그대로 보입니다.
- **새로 추가한 것**: 주소록·일기·메모를 새로 추가하면, 정해 둔 순서의 맨 아래에 붙습니다.
- **계정과목 순서**: 입력할 때 고르는 목록과 결산 보고서에도 그대로 쓰입니다.
- **고를 수 있는 색**: 포인트·바탕·카드·글자·수입 글자·지출 글자 6가지입니다.
  - 견본을 누르면 색 고르기 창이 뜹니다. 색 견본, 색상·채도·밝기 막대, #RRGGBB 직접 입력으로 고릅니다.
  - 테두리나 흐린 글자 같은 나머지 색은 고른 색에 맞춰 자동으로 바뀝니다.
  - 바탕을 밝게 하면 미니홈피 맨 위 글자가 자동으로 진해집니다.

## 2-3. 연·월 바로 고르기 · 그래프 종류 (1.2.0)

**연·월 바로 고르기**: 가계부·달력·결산·일기장·자산(카드) 화면의 `◀ 2026년 10월 ▾ ▶` 에서 **가운데 글자를 누르면** 고르기 창이 뜹니다.

- 위쪽은 연도 12개입니다. **‹ ›** 로 12해씩 넘깁니다 (1900~2100년).
- 연도를 누른 뒤 아래 **달**을 누르면 그 달로 바로 갑니다.
- 연도만 쓰는 화면(그래프, 결산의 년결산·예산)은 연도를 누르면 바로 바뀝니다.
- 지금 보고 있는 연·월은 색으로 칠해져 있고, 오늘이 있는 해·달은 밑줄로 표시됩니다.
- 아래 **이번 달**(연도만 고를 때는 **올해**)을 누르면 오늘로 돌아옵니다.
- ◀▶ 로 한 칸씩 넘기는 것은 그대로 됩니다.
- 예전에는 가운데 글자를 누르면 바로 이번 달로 갔습니다. 이제는 창 안의 **이번 달**을 누르세요.

**그래프 종류**: 더보기 → 그래프의 종류 단추로 고릅니다. 고른 종류는 이 휴대폰에 기억됩니다.

| 종류 | 보여 주는 것 |
|---|---|
| 꺾은선 | 기간(달 또는 날)별 금액을 선으로 |
| 막대 | 기간마다 항목별 막대를 나란히 |
| 누적 막대 | 기간마다 항목 막대를 쌓음 — 막대 높이가 그 기간 합계 |
| 영역 | 꺾은선 아래를 옅게 칠함 |
| 누계 | 처음부터 차례로 더해 간 금액 |
| 가로 막대 | 항목별 합계를 큰 것부터 |
| 원 | 항목별 합계의 비율(%) |
| 도넛 | 원 + 가운데에 합계 |

- 원·도넛은 합계가 0보다 큰 항목만 그립니다. 합계가 0 이하인 항목(환불 등)은 빼고, 몇 개를 뺐는지 아래에 적습니다.
- 그래프 아래 표는 종류와 상관없이 원래 금액입니다.

## 3. PC와 자료 주고받기

자료 파일 형식(`.sqlite3`)이 PC판과 같아서 그대로 옮기면 됩니다.

### PC → 휴대폰

1. PC판 **설정 → 암호 · 백업 → 지금 백업하기**를 누릅니다.
   - 백업 폴더 안 `backup(날짜)` 폴더에 `gagyebu.sqlite3` 파일이 생깁니다.
2. 그 파일을 휴대폰으로 옮깁니다.
3. 앱 **더보기 → 설정 → 백업 · 복원 → 파일에서 가져오기**를 누르고 그 파일을 고릅니다.

### 휴대폰 → PC

1. 앱 **설정 → 백업 · 복원 → 파일로 내보내기**를 누릅니다.
   - 저장 위치를 고르면 `gagyebu-날짜.sqlite3` 파일이 저장됩니다. '다운로드' 폴더나 구글 드라이브를 고르면 됩니다.
2. 그 파일을 PC로 옮깁니다.
3. PC판 **설정 → 암호 · 백업 → 백업 파일로 복원하기…**로 엽니다.

### 주의

- 가져오기는 휴대폰 자료를 파일 내용으로 **통째로 바꿉니다.** 두 곳에서 따로 입력한 내용을 합쳐 주지는 않습니다. 한쪽에서 입력하고 파일을 옮겨 이어 쓰세요.
- 가져오기 직전 자료는 앱 안에 자동 보관됩니다. **설정 → 앱 안 보관본**에서 되돌릴 수 있습니다.
- 우리집 가계부 자료 파일이 아닌 파일을 고르면 거부하고, 지금 자료는 그대로 둡니다.

## 4. 암호

- **초기 암호: 없음**
- **설정·바꾸기·해제**: 더보기 → 설정 → 시작 암호
- **PC판과의 관계**
  - 암호 저장 방식이 PC판과 같아서, 자료 파일을 옮기면 암호도 같이 옮겨집니다.
  - PC에서 암호를 건 파일을 가져오면, 다음에 앱을 열 때 그 암호를 묻습니다.
- **암호를 잊었을 때**
  - PC판에서 같은 자료의 암호를 지운 뒤 백업 파일로 다시 옮기세요.
  - 또는 휴대폰 **설정 → 애플리케이션 → 우리집 가계부 → 저장공간 → 데이터 삭제**를 하면 앱이 처음 상태가 됩니다. 이때 **모든 자료가 지워집니다.**

## 6. 앱 업데이트

- **새 버전 설치**: 새 APK를 그대로 설치하면 덮어 설치되고 자료는 남습니다. 같은 서명 키로 만든 APK여야 합니다.
- **앱을 지웠다 다시 설치하면** 앱 안 자료가 지워집니다. 먼저 '파일로 내보내기'를 하세요.
- **서명 키**: 업데이트용 서명 키 `packaging/gagyebu-release.jks`와 암호 파일 `keystore-password.txt`를 함께 보관해야 같은 앱으로 업데이트할 수 있습니다. 둘 다 원본 묶음에 들어 있습니다.

## 8. 확인한 것과 확인 필요

### 확인함

- **PC판과 결과가 같은지**: 같은 자료 파일을 PC판 코드와 안드로이드판 코드로 각각 계산해 비교했습니다. 방향은 두 가지(안드로이드판이 만든 자료, PC판이 만든 자료)이고, 항목은 106개·80개입니다.
  - 비교한 것: 잔액, 월·년·일일·기간 결산, 예산, 그래프 값, 검색, 예약 입력 대상, 자산 요약, 통장 잔액, 카드 할부·결제일, 기념일(음력 포함), 반복 일정, 음력 변환, 암호 확인
  - 결과: 화면 안내 문구 하나(예산 보고서) 말고 모두 같았습니다.
- **화면 조작**: 화면을 직접 눌러 확인했습니다 (입력·수정·삭제·자동완성, 예약 입력, 반복 일정, 예산, 통장·카드 결제, 주소록·일기·메모, CSV 불러오기, 테마, 암호, 내보내기·가져오기).
  - 쓴 환경: PC의 크로미움 브라우저 + SQLite 웹어셈블리, 휴대폰 크기(392×820) 화면
  - 결과: 40개 항목이 모두 통과했습니다.
- **테마 (1.1.0)**: 테마 5개 × 화면 8개를 360·412px 폭에서 그려 오류·가로 넘침이 없음을 확인했습니다. 위의 화면 조작 시험 40개를 피드·타임라인(밝게/어둡게) 테마에서도 다시 돌려 모두 통과했습니다.
- **순서·색 바꾸기**: 화면을 끌고 눌러 28개 항목을 확인했고 모두 통과했습니다. 끌어다 놓기와 ▲▼는 메뉴·화면 구성·같은 날 내역·대분류·소분류·주소록·일기·메모에서 확인했고, 색은 테마 4가지에서 확인했습니다.
  - PC판과 같은 자료 파일에서 순서가 똑같이 나오는지도 비교했습니다 (대분류·소분류·같은 날 내역·검색·주소록·일기·메모).
  - 순서는 자료 파일의 설정 표(meta)와 원래 있던 순서 칸에 저장합니다. 예전 판(PC 1.1.1, 안드로이드 1.0.0) 코드로 그 파일을 열어 읽기·장부 복사·계정 추가·입력을 해 봤고, 오류가 없었습니다. 예전 판에서는 순서만 기본으로 보이고, 다시 새 판으로 열면 정한 순서가 그대로 남아 있습니다.
- **연·월 고르기·그래프 종류 (1.2.0)**: 화면을 눌러 테마 4가지(미니홈피·기본·피드·타임라인 어둡게)에서 확인했고 모두 통과했습니다.
  - 그래프 8종: 단추를 누를 때마다 그림 종류가 바뀌고 휴대폰에 기억되는지, 막대·조각 수, 누적 막대 조각이 틈 없이 쌓이는지, 원·도넛 비율 합 100%와 0 이하 항목 제외, 가로 막대가 합계 큰 순서인지, 화면 가로 넘침이 없는지
  - 연·월 고르기: 가계부·달력·결산·일기장에서 12해 앞으로 넘겨 다른 해 3월로 바로 이동, ▶ 한 달 이동, 이번 달 / 그래프의 연도 고르기와 올해
  - 그림을 찍어 눈으로 확인했습니다 (`devtools/shots/graph/`).
- **암호 계산**: 앱의 자바 코드가 PC판(파이썬)과 같은 결과를 냅니다 (PC의 자바로 시험함).
- **APK**: 서명 v2·v3, 최소 버전 24(안드로이드 7.0), 대상 버전 34로 만들어졌습니다.
- **코드 검토**: 안드로이드 쪽 자바 코드를 따로 검토하고, 나온 문제를 고쳤습니다.
  - 손상된 자료 파일을 지우지 않고 따로 옮겨 둠
  - 가져오기는 파일을 끝까지 검사(quick_check)한 뒤 한 번에 바꿔 끼움
  - 화면 엔진이 죽어도 앱 전체가 꺼지지 않음

### 확인 필요

- **실제 휴대폰에서 설치·실행·파일 주고받기**: 이 작업 환경에는 안드로이드 기기와 에뮬레이터가 없어서 직접 돌려 보지 못했습니다. 안드로이드 쪽 자바 코드(SQLite 연결, 파일 선택 창)는 코드 검토만 했습니다.
- **상태 표시줄 색**: 피드·타임라인 테마에서 맨 위 상태 표시줄을 흰색/검은색으로 바꾸는 부분은 실제 휴대폰에서 확인하지 못했습니다.
- **CP949(엑셀 기본) CSV**: 휴대폰마다 지원하는 문자셋 이름이 달라 일부 글자가 깨질 수 있습니다. UTF-8 CSV는 문제없습니다.

## 9. 휴대폰에서 처음 해 볼 것 (문제가 있으면 어느 단계인지 알려 주세요)

- [ ] 설치되고 앱 아이콘(고양이)이 보인다
- [ ] 앱을 열면 미니홈피 화면이 뜬다 (흰 화면이나 오류 문구가 아님)
- [ ] ＋ 버튼으로 내역 하나를 넣고, 앱을 완전히 껐다 켜도 남아 있다
- [ ] 설정 → 파일로 내보내기 → 저장 위치를 고르면 "저장했습니다" 안내가 나온다
- [ ] 그 파일을 PC로 옮겨 PC판 '백업 파일로 복원하기…'로 열린다
- [ ] PC판 '지금 백업하기'로 만든 파일을 앱 '파일에서 가져오기'로 열면 PC 내역이 보인다
- [ ] 암호를 설정하고 앱을 다시 열면 암호를 묻는다
- [ ] 뒤로 버튼이 창 → 화면 → 앱 종료 순서로 동작한다
