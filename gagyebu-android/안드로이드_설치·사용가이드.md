# 우리집 가계부 — 안드로이드판 설치·사용 가이드 (1.5.0)

PC판(리눅스·윈도우)과 같은 자료 파일을 쓰는 안드로이드 앱입니다. 자료 파일을 주고받으면 PC에서 쓰던 장부를 휴대폰에서 이어 쓸 수 있고, 반대로도 됩니다.

## 1. 설치

| 순서 | 할 일 |
|---|---|
| 1 | `우리집가계부-안드로이드-1.5.0.apk` 파일을 휴대폰으로 옮깁니다 (USB, 카카오톡 '나에게 보내기', 구글 드라이브 등). GitHub 릴리스에서 받으면 이름이 `gagyebu-android-1.5.0.apk`입니다. |
| 2 | 휴대폰의 **내 파일**(또는 파일·다운로드) 앱에서 그 파일을 누릅니다. |
| 3 | "출처를 알 수 없는 앱" 안내가 나오면 **설정 → 이 출처 허용**을 켜고 돌아와 **설치**를 누릅니다. |
| 4 | Play 프로텍트가 "알 수 없는 개발자" 경고를 띄우면 **세부정보 → 그래도 설치**를 누릅니다. 플레이 스토어를 거치지 않은 앱이라 나오는 경고입니다. |

- **필요한 안드로이드 버전**: 7.0 이상
- **필요한 WebView**: 휴대폰의 'Android System WebView'(또는 Chrome)가 2019년 이후 버전이어야 합니다. 플레이 스토어가 보통 자동으로 업데이트합니다. 너무 오래되었으면 앱이 업데이트하라고 알려 줍니다.
- **권한**: 이 앱은 인터넷·저장소·연락처 권한을 쓰지 않습니다. 파일을 주고받을 때만 시스템 파일 선택 창을 엽니다.

## 2. 처음 실행

- 암호 없이 바로 열립니다. 장부는 **가계부 장부**와 **생활비·용돈·비상금·여행 장부**(계정과목은 같고 내역은 빈 장부)로 시작합니다. PC판 처음 상태와 같습니다.
- 아래 탭: **가계부 · 달력 · 결산 · 자산 · 더보기**
  - 더보기에는 검색·그래프·예약 입력·기념일·주소록·일기장·메모장·설정·도움말이 있습니다.
- 휴대폰의 **뒤로** 버튼은 열린 창 → 하위 화면 → 가계부 탭 순서로 닫고, 마지막에 앱을 끕니다.

## 2-1. 테마 (더보기 → 설정 → 화면 꾸미기)

| 테마 | 모양 |
|---|---|
| 미니홈피 (기본) | 2000년대 미니홈피 느낌, 아늑단 이미지, 도트 글꼴 |
| 기본 | 깔끔한 흰 화면 |
| 피드 (사진 SNS 모양) | 화면 전체가 사진 SNS 앱처럼 (아래 표) |
| 타임라인 (짧은 글 SNS 모양) | 화면 전체가 짧은 글 SNS 앱처럼 (아래 표) |

1.5.0부터 피드·타임라인은 **화면 구성이 SNS 앱처럼** 바뀌었습니다. 기능은 그대로입니다.

| | 피드 | 타임라인 |
|---|---|---|
| 맨 위 줄 | 손글씨 로고 · 장부 고르기 · ⤓(CSV) · 화면 구성 · ⊕(새 내역) | 내 동그라미(누르면 더보기) · 가운데 고양이 · 장부 고르기 |
| 아래 탭 | 아이콘만, 마지막 칸은 내 미니미 | 아이콘만 |
| 가계부 위쪽 | 프로필 머리: 큰 미니미 · 이달 수입/지출/차액 · 장부 이름 · 기분·다짐·오늘 지출·잔액 → 달 이동 → [＋새 내역]과 지출 많은 계정 동그라미 → 탭 [10월 · 전체 기간 · 정렬] | 맨 위에 붙은 탭 [10월 · 전체 기간 · 정렬] → 달 이동 → 고정된 글(이달 요약) → 많이 쓴 곳 순위 |
| 목록 | 하루 = 게시물: 사진 칸(그날 금액·디카 날짜 도장·고양이), ♥(수입 있는 날) 💬(이 날 새 내역) ⇅(순서) 📅(달력에서 보기), ⋯ 메뉴, 내역은 게시물 글처럼 (5건 이상은 '모두 보기') | 한 건 = 글: 품목 @계정 · 날짜 · 메모 · 금액, 💬(수정) 🔁(같은 내용 다시 입력) ♥(수입) 📊(잔액) |
| 새 내역 | 맨 위 ⊕ | 오른쪽 아래 분홍 단추 |

- 계정 동그라미·많이 쓴 곳을 누르면 그 계정을 그 기간으로 검색합니다.
- **🔁 다시 입력**: 그 내역 내용을 오늘 날짜 새 내역 창에 채웁니다 (고쳐서 저장, 원래 내역은 그대로).
- 더보기 화면은 아이콘 목록입니다.

피드·타임라인은 색을 3가지 중에서 고릅니다 (1.3.0부터, 기본은 미니홈피 색).

| 색 | 모양 |
|---|---|
| 미니홈피 색 | 청록 바탕(물방울 점) + 흰 카드, 맨 위는 흰 글자. 피드는 분홍, 타임라인은 청록 포인트 |
| 밝게 | 흰 바탕. 피드는 분홍, 타임라인은 파란 포인트 |
| 어둡게 | 검은 바탕. 피드는 분홍, 타임라인은 파란 포인트 |

- 1.2.0까지의 '피드'·'타임라인(밝게)'는 지금의 '피드 · 밝게'·'타임라인 · 밝게'입니다. 1.3.0에서 '피드'·'타임라인'은 미니홈피 색이 되었습니다.

- 피드·타임라인은 기능이 같고 모양만 다릅니다. 내역을 누르면 똑같이 수정 창이 뜹니다.
- 피드·타임라인은 휴대폰 기본 글꼴을 쓰고(설정에서 추가 글꼴을 고르면 그 글꼴), 맨 위 상태 표시줄 색도 테마에 맞춥니다.
- 실제 SNS 서비스의 로고·이름은 쓰지 않았습니다.

## 2-2. 순서 바꾸기 · 색 바꾸기

순서 바꾸기 창에서는 줄 왼쪽의 **☰ 를 눌러 끌거나**, 오른쪽 **▲▼** 로 옮긴 뒤 **저장**을 누릅니다. **기본 순서로**를 누르면 처음 순서로 돌아갑니다.

| 무엇 | 어디서 | 어디에 저장 |
|---|---|---|
| 메뉴 순서 | 더보기 화면 오른쪽 위 **메뉴 순서**, 또는 설정 → 화면 꾸미기 | 이 휴대폰 (위 4개 = 아래 탭, 맨 위 = 처음 화면) |
| 가계부 화면 구성 | 가계부 화면 오른쪽 위 **☰**, 또는 설정 → 화면 꾸미기 | 이 휴대폰 |
| 같은 날 내역 순서 | 가계부 목록의 날짜 옆 **⇅** | 자료 파일 → PC판에서도 같은 순서 |
| 계정과목 순서 (대분류·소분류) | 설정 → 계정과목 → **대분류 순서 바꾸기** / 대분류 옆 **소분류 순서** | 자료 파일 → PC판에서도 같은 순서 |
| 주소록·일기장·메모장 순서 | 각 화면 오른쪽 위 **순서** | 자료 파일 → PC판에서도 같은 순서 |
| 테마 색 | 설정 → 화면 꾸미기 → **이 테마의 색** | 이 휴대폰 (테마마다 따로) |

- **같은 날 내역 순서**: 잔액도 정한 순서대로 계산됩니다. '최근 것을 위로'를 켜도, 순서를 정한 날은 정한 순서 그대로 보입니다.
- **새로 추가한 것**: 주소록·일기·메모를 새로 추가하면, 정해 둔 순서의 맨 아래에 붙습니다.
- **계정과목 순서**: 입력할 때 고르는 목록과 결산 보고서에도 그대로 쓰입니다.
- **고를 수 있는 색**: 포인트·바탕·카드·글자·수입 글자·지출 글자 6가지입니다.
  - 견본을 누르면 색 고르기 창이 뜹니다. 색 견본, 색상·채도·밝기 막대, #RRGGBB 직접 입력으로 고릅니다.
  - 테두리나 흐린 글자 같은 나머지 색은 고른 색에 맞춰 자동으로 바뀝니다.
  - 바탕을 밝게 하면 미니홈피 맨 위 글자가 자동으로 진해집니다.

## 2-3. 연·월 바로 고르기 · 그래프 종류 (1.2.0)

**연·월 바로 고르기**: 가계부·달력·결산·일기장·자산(카드) 화면의 `◀ 2026년 10월 ▾ ▶` 에서 **가운데 글자를 누르면** 고르기 창이 뜹니다.

- 위쪽은 연도 12개입니다. **‹ ›** 로 12해씩 넘깁니다 (1900~2100년).
- 연도를 누른 뒤 아래 **달**을 누르면 그 달로 바로 갑니다.
- 연도만 쓰는 화면(그래프, 결산의 년결산·예산)은 연도를 누르면 바로 바뀝니다.
- 지금 보고 있는 연·월은 색으로 칠해져 있고, 오늘이 있는 해·달은 밑줄로 표시됩니다.
- 아래 **이번 달**(연도만 고를 때는 **올해**)을 누르면 오늘로 돌아옵니다.
- ◀▶ 로 한 칸씩 넘기는 것은 그대로 됩니다.
- 예전에는 가운데 글자를 누르면 바로 이번 달로 갔습니다. 이제는 창 안의 **이번 달**을 누르세요.

**그래프 종류**: 더보기 → 그래프의 종류 단추로 고릅니다. 고른 종류는 이 휴대폰에 기억됩니다.

| 종류 | 보여 주는 것 |
|---|---|
| 꺾은선 | 기간(달 또는 날)별 금액을 선으로 |
| 막대 | 기간마다 항목별 막대를 나란히 |
| 누적 막대 | 기간마다 항목 막대를 쌓음 — 막대 높이가 그 기간 합계 |
| 영역 | 꺾은선 아래를 옅게 칠함 |
| 누계 | 처음부터 차례로 더해 간 금액 |
| 가로 막대 | 항목별 합계를 큰 것부터 |
| 원 | 항목별 합계의 비율(%) |
| 도넛 | 원 + 가운데에 합계 |

- 원·도넛은 합계가 0보다 큰 항목만 그립니다. 합계가 0 이하인 항목(환불 등)은 빼고, 몇 개를 뺐는지 아래에 적습니다.
- 그래프 아래 표는 종류와 상관없이 원래 금액입니다.

## 2-4. 업데이트 (1.3.0)

새 버전이 나오면 앱을 켤 때 알려 줍니다. GitHub 릴리스를 확인합니다.

1. 새 버전이 있으면 **업데이트 내용**을 간단히 보여 주고 "업데이트하시겠습니까?"를 묻습니다.
   - **아니요**: "설정 → 업데이트에서 언제든 직접 새 버전을 확인하고, 내려받아 설치할 수 있습니다"라고 알려 줍니다.
   - **예**: 새 APK를 내려받습니다. 진행 막대가 나오고, 휴대폰 알림 창에서도 볼 수 있습니다.
2. 다 받으면 "지금 설치할까요?"를 묻습니다.
   - **아니요**: 설정 → 업데이트의 [내려받은 새 버전 설치]로 나중에 설치합니다.
   - **예**: 안드로이드 설치 화면이 열립니다.
     - 처음이면 "이 출처의 앱 설치 허용"을 켜 달라는 화면이 먼저 나옵니다. 켜고 돌아오면 설치를 이어 갑니다.
     - 가계부 자료는 그대로 남습니다 (같은 서명 키로 덮어 설치).

- **설정 → 업데이트**: 앱을 켤 때 자동 확인 켜기·끄기, [업데이트 확인], [새 버전 내려받기], [내려받은 새 버전 설치], 새 버전의 업데이트 내용.
- **권한**: 1.3.0부터 '인터넷'과 '앱 설치 요청' 권한을 씁니다. 새 버전 확인과 새 APK 받기에만 쓰고, 가계부 자료는 어디에도 보내지 않습니다.
- 받은 APK는 릴리스에 적힌 크기·SHA-256과 맞을 때만 설치 화면을 엽니다.
- 인터넷이 안 되면 켤 때는 조용히 넘어가고, [업데이트 확인]을 눌렀을 때만 알려 줍니다.
- 이 기능은 1.3.0부터 들어 있습니다. 1.2.0 이하에서 1.3.0으로는 예전처럼 APK를 직접 설치해야 합니다.

## 2-5. 장부 여러 개 · 글자 크기 (1.4.0)

**기본 장부**: 가계부 장부 말고도 **생활비 장부 · 용돈 장부 · 비상금 장부 · 여행 장부**를 만들어 둡니다.
- 계정과목은 첫 장부에서 복사하고, 내역은 비어 있습니다.
- 1.4.0에서 자료를 처음 열 때 **한 번만** 만듭니다. 같은 이름의 장부가 이미 있으면 건너뜁니다.
- 필요 없는 장부는 설정 → 장부 관리에서 지우면 다시 생기지 않습니다. PC판 1.5.0도 같은 규칙이라 어느 쪽에서 먼저 열어도 한 번만 생깁니다.
- PC에서 가져온 예전 자료에도 처음 한 번 더해집니다.

**맨 위 장부 목록에서 바로 새 장부**: 목록 맨 아래 **＋ 새 장부 만들기**를 고르면 이름과 만드는 방법을 묻습니다.

| 만드는 방법 | 내용 |
|---|---|
| 빈 장부 | 대분류 '수입'만 있는 장부 |
| 지금 장부의 계정과목만 복사 (기본) | 계정과목만 가져오고 내역은 비어 있음 |
| 지금 장부를 통째로 복사 | 내역·예산·예약·품목까지 복사 |

- 저장하면 바로 그 장부로 바뀝니다. 목록의 **장부 관리…** 는 장부 관리 창을 엽니다 (이름·비우기·삭제).

**글자 크기 (1px 단위)**: 설정 → 화면 꾸미기 → **글자 크기**에서 **－ / ＋** 로 1픽셀씩, 또는 막대를 끌어 바꿉니다 (10~26px). 바꾸면 바로 보입니다.
- **기본**: 테마의 원래 크기로 (미니홈피 14px, 피드·타임라인 15px).
- 1.3.0까지 고른 '작게·보통·크게·아주 크게'는 같은 크기의 px 로 그대로 이어집니다.
- 테마를 바꿔도 정한 크기가 유지됩니다. 이 휴대폰에만 저장됩니다.

## 2-6. 설정 화면 · 글꼴 (1.5.0)

**설정**은 묶음별 목록입니다 (아이콘 · 이름 · 지금 값 · ›). 맨 위 내 프로필 줄을 누르면 미니미·기분·한마디를 바꿉니다.

| 묶음 | 줄 |
|---|---|
| 장부 | 장부 관리 · 계정과목 · 품목 자동완성 · 결산일 |
| 화면 | 화면 꾸미기(테마·글꼴·글자 크기·순서·색·전광판) · 내 프로필(미니미·기분·한마디) |
| 백업 | 백업 파일 저장 · 백업 파일 보내기 |

## 3. PC와 자료 주고받기 · 백업

자료 파일 형식(`.sqlite3`)이 PC판과 같아서 그대로 옮기면 됩니다. 백업 파일 이름은 `우리집가계부-백업-날짜.sqlite3`입니다.

### 백업하기 (설정 → 백업)

| 줄 | 하는 일 |
|---|---|
| 백업 파일 저장 | 안드로이드 저장 창이 열립니다. 왼쪽 위 **☰** 를 눌러 **내 파일**(내장 메모리의 원하는 폴더·다운로드 등)이나 **Google Drive** 를 고르고, 폴더를 정해 저장합니다. |
| 백업 파일 보내기 | 공유 창이 열립니다. **카카오톡·디스코드**·메일·드라이브 등 고른 앱으로 파일을 보냅니다. |

### 불러오기 (설정 → 백업 불러오기)

| 줄 | 하는 일 |
|---|---|
| 백업 파일 불러오기 | 안드로이드 파일 고르기 창이 열립니다. ☰ 에서 내 파일·다운로드·Google Drive 중 파일이 있는 곳을 고릅니다. |
| 다른 앱에서 불러오기 | 먼저 앱을 고릅니다 (**삼성 '내 파일'**, Files, 드라이브 등). 그 앱 안에서 경로를 따라가 파일을 고릅니다. |
| 앱 안 보관본 | 하루 한 번 자동 보관본·불러오기 직전 자료로 되돌립니다. |

- Google Drive 는 휴대폰에 드라이브 앱이 깔려 있고 로그인되어 있어야 저장·불러오기 창에 보입니다.
- 카카오톡으로 받은 백업 파일은 카카오톡에서 **저장**한 뒤(보통 내 파일 → Download → KakaoTalk) 불러오기에서 고르세요.

### PC → 휴대폰

1. PC판 **설정 → 암호 · 백업 → 구글 드라이브에 저장** (또는 **카톡·디스코드로 보내기**, **다른 곳에 저장…**)
2. 앱 **설정 → 백업 불러오기 → 백업 파일 불러오기**로 그 파일을 고릅니다.

### 휴대폰 → PC

1. 앱 **설정 → 백업 → 백업 파일 저장**(Google Drive·내 파일) 또는 **백업 파일 보내기**(카톡·디스코드)
2. PC판 **설정 → 암호 · 백업 → 구글 드라이브에서 복원…** 또는 **백업 파일로 복원하기…**로 엽니다.

### 주의

- 가져오기는 휴대폰 자료를 파일 내용으로 **통째로 바꿉니다.** 두 곳에서 따로 입력한 내용을 합쳐 주지는 않습니다. 한쪽에서 입력하고 파일을 옮겨 이어 쓰세요.
- 가져오기 직전 자료는 앱 안에 자동 보관됩니다. **설정 → 백업 불러오기 → 앱 안 보관본**에서 되돌릴 수 있습니다.
- 우리집 가계부 자료 파일이 아닌 파일을 고르면 거부하고, 지금 자료는 그대로 둡니다.

## 4. 암호

## 8. 확인한 것과 확인 필요

### 확인함

- **PC판과 결과가 같은지**: 같은 자료 파일을 PC판 코드와 안드로이드판 코드로 각각 계산해 비교했습니다. 방향은 두 가지(안드로이드판이 만든 자료, PC판이 만든 자료)이고, 항목은 106개·80개입니다.
  - 비교한 것: 잔액, 월·년·일일·기간 결산, 예산, 그래프 값, 검색, 예약 입력 대상, 자산 요약, 통장 잔액, 카드 할부·결제일, 기념일(음력 포함), 반복 일정, 음력 변환, 암호 확인
  - 결과: 화면 안내 문구 하나(예산 보고서) 말고 모두 같았습니다.
- **화면 조작**: 화면을 직접 눌러 확인했습니다 (입력·수정·삭제·자동완성, 예약 입력, 반복 일정, 예산, 통장·카드 결제, 주소록·일기·메모, CSV 불러오기, 테마, 암호, 내보내기·가져오기).
  - 쓴 환경: PC의 크로미움 브라우저 + SQLite 웹어셈블리, 휴대폰 크기(392×820) 화면
  - 결과: 40개 항목이 모두 통과했습니다.
- **테마 (1.1.0)**: 테마 5개 × 화면 8개를 360·412px 폭에서 그려 오류·가로 넘침이 없음을 확인했습니다. 위의 화면 조작 시험 40개를 피드·타임라인(밝게/어둡게) 테마에서도 다시 돌려 모두 통과했습니다.
- **순서·색 바꾸기**: 화면을 끌고 눌러 28개 항목을 확인했고 모두 통과했습니다. 끌어다 놓기와 ▲▼는 메뉴·화면 구성·같은 날 내역·대분류·소분류·주소록·일기·메모에서 확인했고, 색은 테마 4가지에서 확인했습니다.
  - PC판과 같은 자료 파일에서 순서가 똑같이 나오는지도 비교했습니다 (대분류·소분류·같은 날 내역·검색·주소록·일기·메모).
  - 순서는 자료 파일의 설정 표(meta)와 원래 있던 순서 칸에 저장합니다. 예전 판(PC 1.1.1, 안드로이드 1.0.0) 코드로 그 파일을 열어 읽기·장부 복사·계정 추가·입력을 해 봤고, 오류가 없었습니다. 예전 판에서는 순서만 기본으로 보이고, 다시 새 판으로 열면 정한 순서가 그대로 남아 있습니다.
- **연·월 고르기·그래프 종류 (1.2.0)**: 화면을 눌러 테마 4가지(미니홈피·기본·피드·타임라인 어둡게)에서 확인했고 모두 통과했습니다.
  - 그래프 8종: 단추를 누를 때마다 그림 종류가 바뀌고 휴대폰에 기억되는지, 막대·조각 수, 누적 막대 조각이 틈 없이 쌓이는지, 원·도넛 비율 합 100%와 0 이하 항목 제외, 가로 막대가 합계 큰 순서인지, 화면 가로 넘침이 없는지
  - 연·월 고르기: 가계부·달력·결산·일기장에서 12해 앞으로 넘겨 다른 해 3월로 바로 이동, ▶ 한 달 이동, 이번 달 / 그래프의 연도 고르기와 올해
  - 그림을 찍어 눈으로 확인했습니다 (`devtools/shots/graph/`).

  - 화면 엔진이 죽어도 앱 전체가 꺼지지 않음

### 확인 필요

- **실제 휴대폰에서 설치·실행·파일 주고받기**: 이 작업 환경에는 안드로이드 기기와 에뮬레이터가 없어서 직접 돌려 보지 못했습니다. 안드로이드 쪽 자바 코드(SQLite 연결, 파일 선택 창)는 코드 검토만 했습니다.
- **업데이트의 실제 동작**: 휴대폰에서 새 버전 확인(인터넷), 시스템 내려받기 관리자로 받기, '이 출처 허용' 화면, 설치 화면이 실제로 열리는지는 확인하지 못했습니다. 1.3.0 이상이 설치된 휴대폰에서 새 버전(예: 1.5.0)으로 올릴 때 확인할 수 있습니다.
- **상태 표시줄 색**: 피드·타임라인 테마에서 맨 위 상태 표시줄을 흰색/검은색으로 바꾸는 부분은 실제 휴대폰에서 확인하지 못했습니다.
- **백업 보내기·다른 앱에서 불러오기의 실제 동작**: 공유 창(카카오톡·디스코드), '내 파일' 같은 앱을 먼저 고르는 창은 시험 환경(브라우저)에서는 가짜로만 시험했습니다. 자바 코드는 컴파일만 확인했습니다.
- **CP949(엑셀 기본) CSV**: 휴대폰마다 지원하는 문자셋 이름이 달라 일부 글자가 깨질 수 있습니다. UTF-8 CSV는 문제없습니다.

## 9. 휴대폰에서 처음 해 볼 것 (문제가 있으면 어느 단계인지 알려 주세요)

- [ ] 설치되고 앱 아이콘(고양이)이 보인다
- [ ] 앱을 열면 미니홈피 화면이 뜬다 (흰 화면이나 오류 문구가 아님)
- [ ] ＋ 버튼으로 내역 하나를 넣고, 앱을 완전히 껐다 켜도 남아 있다
- [ ] 설정 → 백업 파일 저장 → 저장 창에서 Google Drive(또는 내 파일의 폴더)를 골라 저장하면 "저장했습니다" 안내가 나온다
- [ ] 설정 → 백업 파일 보내기 → 공유 창에 카카오톡·디스코드가 보이고, 보내면 파일이 간다
- [ ] 그 파일을 PC로 옮겨 PC판 '백업 파일로 복원하기…'로 열린다
- [ ] PC판에서 만든 백업 파일을 앱 '백업 파일 불러오기'(또는 '다른 앱에서 불러오기' → 내 파일)로 열면 PC 내역이 보인다
- [ ] 암호를 설정하고 앱을 다시 열면 암호를 묻는다
- [ ] 뒤로 버튼이 창 → 화면 → 앱 종료 순서로 동작한다
