1. 처음 암호
----------------------------------------------------------------------
  ■ 새로 설치하고 처음 실행하면: 암호가 없습니다.
    → 암호 창 없이 바로 열립니다.

  ■ 예전 '우리집 가계부' 자료를 가져왔다면: 예전 프로그램의 시작 암호가
    그대로 옮겨집니다.
    → 예전 프로그램에서 암호를 바꾼 적이 없다면 초기 암호는  1111  입니다.

  ■ 암호 창에서 틀리게 넣으면 "암호가 틀렸습니다 (n회)"가 나오고
    다시 넣을 수 있습니다. 횟수 제한은 없습니다.


----------------------------------------------------------------------
2. 암호 설정 · 바꾸기 · 없애기
----------------------------------------------------------------------
  모두 [설정] → 위쪽 탭 [암호 · 백업] → '시작 암호' 칸에서 합니다.
  ([설정]은 화면 오른쪽 탭 맨 아래에 있습니다. 기본 화면이면 왼쪽 목록 맨 아래)
  지금 상태는 '현재: 암호 사용 중' 또는 '현재: 암호 없음'으로 보입니다.

  ■ 처음 설정하기 (현재: 암호 없음)
    1) [암호 설정/변경] 단추를 누릅니다.
    2) '새 암호' 창에 원하는 암호를 넣고 [확인]
    3) '새 암호 확인' 창에 같은 암호를 한 번 더 넣고 [확인]
    4) "암호를 설정했습니다. 다음 실행부터 암호를 물어봅니다." → 끝
       (프로그램을 다시 켤 때부터 암호를 물어봅니다)

  ■ 바꾸기 (현재: 암호 사용 중)
    1) [암호 설정/변경]
    2) '현재 암호' 창에 지금 암호를 넣고 [확인]
       (틀리면 "현재 암호가 틀렸습니다." 나오고 그대로 끝)
    3) '새 암호' → '새 암호 확인'에 새 암호를 두 번 넣고 [확인]

  ■ 없애기 (암호 없이 쓰기)
    1) [암호 해제]
    2) '현재 암호' 창에 지금 암호를 넣고 [확인]
    3) '현재: 암호 없음'으로 바뀌면 끝 → 다음 실행부터 암호 창이 안 뜹니다.

  ■ 알아 둘 점
    - 빈 칸은 암호로 설정되지 않습니다.
    - 대문자/소문자, 한글/영문 입력 상태를 구분합니다.
      (암호가 맞는데 안 열리면 한/영 키, Caps Lock 을 확인하세요)
    - 두 번 넣은 암호가 다르면 "두 암호가 다릅니다." 나오고 바뀌지 않습니다.
    - 암호는 원문이 아니라 알아볼 수 없게 바꾼 값(해시)으로 저장됩니다.
    - 이 암호는 '프로그램 열기'만 막습니다. 데이터 파일 자체가 잠기는
      것은 아니므로, 컴퓨터 사용자 계정 암호도 함께 쓰는 것이 좋습니다.

3. 암호를 잊었을 때
----------------------------------------------------------------------
  암호를 되살리는 방법은 없지만, 아래처럼 '암호만 지우면' 자료는 그대로
  두고 다시 들어갈 수 있습니다. 먼저 우리집 가계부를 꼭 닫으세요.

  ■ 방법 1: 암호만 지우는 명령 (자료 그대로, 권장)

    [윈도우] 시작 버튼 → 'cmd' 입력 → '명령 프롬프트'를 열고
            아래 한 줄을 그대로 붙여 넣은 뒤 Enter
            (기본 위치에 설치한 경우)

    "%LOCALAPPDATA%\Programs\Gagyebu\runtime\python.exe" -c "import sqlite3;c=sqlite3.connect(r'%APPDATA%\gagyebu\gagyebu.sqlite3');c.execute('update meta set value=null where key=?',('password',));c.commit();print('OK')"

            → OK 가 나오면 끝. 프로그램을 켜면 암호 없이 열립니다.
            (휴대용 zip 판이면 앞부분의 %LOCALAPPDATA%\Programs\Gagyebu 를
             압축을 푼 폴더 경로로 바꾸세요)

    [리눅스] 터미널에서 아래 한 줄

    python3 -c "import sqlite3,os;c=sqlite3.connect(os.path.expanduser('~/.local/share/gagyebu/gagyebu.sqlite3'));c.execute('update meta set value=null where key=?',('password',));c.commit();print('OK')"

    → 들어간 다음 2번 방법으로 새 암호를 다시 설정하세요.

  ■ 방법 2: 백업 파일로 바꿔 넣기 (백업한 날 이후 자료는 없어짐)
    1) 데이터 폴더(6번 참고)의 gagyebu.sqlite3 를 다른 이름으로 바꿔 둡니다.
    2) 백업 폴더의 backup(날짜)\gagyebu.sqlite3 를 데이터 폴더에 복사합니다.
    → 그 백업을 만들 때의 암호(그때 암호가 없었으면 암호 없음)로 열립니다.

  ■ 방법 3: 예전 '우리집 가계부' 자료를 다시 가져오기
    → 예전 프로그램의 암호(바꾼 적 없으면 1111)로 돌아가지만, 이 프로그램
      에서 새로 넣은 내역은 빠집니다. (빠진 자료는 auto-backup 폴더에 보관됨)

4. 설치 · 제거
----------------------------------------------------------------------
  ■ 윈도우 (윈도우 10/11 64비트, 윈도우 10은 최신 업데이트 권장)
    설치
      1) 우리집가계부-윈도우판-1.6.1-setup.exe 실행
         (GitHub 릴리스에서 받으면 이름이 gagyebu-windows-1.6.1-setup.exe)
      2) 파란 "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]
         (인증서로 서명하지 않은 개인용 프로그램이라 나오는 안내입니다)
      3) [다음] → [설치] → [마침]   ※ 관리자 권한 필요 없음
      → 바탕화면과 시작 메뉴에 '우리집 가계부 (새 버전)'이 생깁니다.
      설치 위치: %LOCALAPPDATA%\Programs\Gagyebu
    설치 없이 쓰기
      우리집가계부-윈도우판-1.6.1-휴대용.zip 을 압축 풀고 안의
      (GitHub 릴리스에서 받으면 이름이 gagyebu-windows-1.6.1-portable.zip)
      '우리집가계부.exe' 실행 (USB 에 넣어 다녀도 됩니다. 단, 데이터는
      그 PC 의 %APPDATA%\gagyebu 에 저장됩니다)
    제거
      설정 → 앱 → '우리집 가계부 (윈도우판 새 버전)' → 제거
      (또는 시작 메뉴 → 우리집 가계부 → 제거)
    ※ 예전 '우리집 가계부 v5.75'와 따로 설치되며, 예전 프로그램과 자료는
      건드리지 않습니다. 바로가기 이름에 '(새 버전)'이 붙은 것이 이 프로그램입니다.

  ■ 쿠분투 / 우분투
    설치: sudo apt install ./gagyebu-linux_1.6.1_all.deb
    제거: sudo apt remove gagyebu-linux
    앱 메뉴 → 사무 → '우리집 가계부 (리눅스판)', 또는 터미널에서 gagyebu

  ■ 페도라:  sudo dnf install ./gagyebu-linux-1.6.1-1.noarch.rpm

  ※ 지우거나 다시 설치해도 가계부 데이터는 지워지지 않습니다.

5. 예전 '우리집 가계부'(윈도우 v5.75) 자료 가져오기
----------------------------------------------------------------------
  1) 예전 프로그램의 data 폴더를 찾습니다. 둘 중 '앞의 것'이 있으면 그쪽이 최신.
     C:\Users\(사용자)\AppData\Local\VirtualStore\Program Files (x86)\우리집 가계부\data
     C:\Program Files (x86)\우리집 가계부\data
     (리눅스에서 가져올 때는 이 폴더를 통째로 USB 등에 복사해 오세요)
  2) [설정] → 탭 [자료 가져오기] → [data 폴더 선택해서 가져오기…]
  3) data 폴더를 고르면 결과가 아래 칸에 나옵니다.
  - 가져오면 지금 데이터를 대신합니다. 그 전 데이터는 데이터 폴더의
    auto-backup 폴더에 자동 보관됩니다.
  - 예전 .mdb 파일은 읽기만 하고 바꾸지 않습니다.
  - 암호는 예전 암호가 옮겨집니다 (1번 참고).
  - 예약(고정 수입·지출)은 예전 프로그램이 마지막으로 자동입력한 날까지는
    처리된 것으로 보고, 그 뒤 날짜만 입력할지 물어봅니다.

6. 데이터 위치 · 백업 · 다른 PC로 옮기기
----------------------------------------------------------------------
  ■ 데이터 파일 (모든 내역이 이 파일 하나에 들어 있음)
    윈도우: %APPDATA%\gagyebu\gagyebu.sqlite3
            (탐색기 주소창에 %APPDATA%\gagyebu 를 넣고 Enter)
    리눅스: ~/.local/share/gagyebu/gagyebu.sqlite3

  ■ 백업
    [설정] → [암호 · 백업] → [지금 백업하기]
    → 백업 폴더(기본: 내 폴더\우리집가계부_백업)\backup(날짜)\gagyebu.sqlite3
    '프로그램을 끌 때 자동 백업'에 체크하면 끌 때마다 자동으로 백업합니다.

  ■ 복원
    [설정] → [암호 · 백업] → [백업 파일로 복원하기…] → 백업 파일 선택
    (지금 데이터는 auto-backup 폴더에 자동 보관된 뒤 바뀝니다)

  ■ 윈도우 ↔ 리눅스, 다른 PC 로 옮기기
    윈도우판과 리눅스판은 같은 데이터 형식입니다.
    보내는 쪽에서 [지금 백업하기] → 백업 파일을 USB 등으로 복사
    → 받는 쪽에서 [백업 파일로 복원하기…]

7. 화면 쓰는 법
----------------------------------------------------------------------
  ■ 메뉴 (오른쪽 탭)
    가계부      : 내역 입력·잔액 (품목을 예전과 같게 쓰면 계정 자동 선택)
    검색하기    : 기간·품목·계정·금액으로 찾기, 고치기·지우기
    결산 보고서 : 월·년·월별 일일·사용자정의 결산, 년예산 (칸 두 번 누르면 상세)
    그래프 분석 : 연간·월간, 그래프 8종 골라 보기, [이미지로 저장]
    예약 설정   : 매달 고정 수입·지출 → 켤 때 '오늘까지 입력될 예약'을 물어봄
    자산관리    : 통장·카드(할부·결제)·증권·보험·부동산
    일정관리    : 달력, 음력, 기념일, 반복 일정, 시작할 때 알림
    주소록 · 일기장 · 메모장
    설정        : 계정과목, 장부 관리, 품목 관리, 암호·백업, 자료 가져오기, 화면 꾸미기

  ■ 가계부 화면 단축키
    Enter = 다음 칸,  F5 = 저장,  Delete = 고른 내역 지우기
    여러 줄을 골라 한꺼번에 지울 수 있습니다.

  ■ 화면 꾸미기 ([설정] → [화면 꾸미기])
    테마  : 미니홈피(2000년대 감성, 기본) / 기본(처음 화면)
            / 피드(사진 SNS 느낌) / 타임라인(짧은 글 SNS 느낌)
            피드·타임라인은 색을 3가지 중에서 고릅니다:
              미니홈피 색(청록 바탕 + 흰 카드) / 밝게(흰 바탕) / 어둡게(검은 바탕)
            (피드·타임라인은 화면이 SNS 앱처럼 바뀝니다: 왼쪽 아이콘 메뉴, 피드는 하루 = 게시물,
             타임라인은 한 건 = 짧은 글. 게시물·글 속 아이콘으로 이 날 새 내역·순서·달력·수정·다시 입력. 기능은 같습니다)
    글꼴  : 도트 글꼴(갈무리) / 시스템 글꼴 / 고운돋움 / 주아 / 개구 / 서툰이야기
            (고운돋움·주아·개구·서툰이야기는 무료 글꼴, 모든 테마에서 쓰임)
    글자 크기: 1픽셀씩 조절 (8~28px), [기본 크기] = 테마 원래 크기. 테마를 바꿔도 유지
    전광판: 맨 위 흐르는 글씨 켜고 끄기
    미니미: 왼쪽 프로필 그림 고르기 (프로필 그림을 눌러도 됨)
    - 왼쪽 프로필의 ◀ 단추로 프로필을 접으면 화면이 넓어집니다.
    - '이번 달 다짐'에 적은 글은 맨 위 전광판에도 흐릅니다.

  ■ 순서 바꾸기 (줄을 끌어다 놓거나 [위로]·[아래로] 단추, 다 되면 [저장])
    메뉴 순서        : [설정] → [화면 꾸미기] → [메뉴 순서 바꾸기…] (맨 위 = 처음 화면)
    가계부 화면 구성 : [설정] → [화면 꾸미기] → [화면 구성 순서…], 입력 상자 오른쪽/왼쪽
    같은 날 내역     : 가계부에서 그날 내역을 하나 고르고 [같은 날 순서…]
    계정과목         : [설정] → [계정과목] → 대분류/소분류의 [순서 바꾸기…]
    주소록·일기·메모 : 각 화면의 [순서 바꾸기…]
    - 메뉴·화면 구성은 이 PC에만, 나머지는 자료 파일에 저장되어 휴대폰판에서도 같은 순서입니다.

  ■ 테마 색 바꾸기 ([설정] → [화면 꾸미기] → 이 테마의 색)
    포인트·바탕·카드·글자·수입 글자·지출 글자 6가지를 고릅니다 (테마마다 따로).
    [처음 색] / [이 테마 색 모두 처음으로]로 되돌립니다.

  ■ 연·월 바로 고르기
    가계부·일정관리·일기장·결산 보고서·자산관리(카드)의 '◀ 2026년 10월 ▼ ▶' 에서
    가운데 글자를 누르면 연·월 고르기 창이 뜹니다.
    연도는 ◀▶ 로 넘기거나 칸에 바로 숫자를 치고, 달 단추를 누르면 그 달로 바로 갑니다.
    [이번 달] = 오늘이 있는 달,  [닫기] = 그대로.  바깥의 ◀▶ 는 전처럼 한 달씩.

  ■ 그래프 종류 ([그래프 분석] → 위쪽 [종류])
    꺾은선 / 막대 / 누적 막대(막대 높이 = 그 기간 합계) / 영역 /
    누계 꺾은선(차례로 더한 금액) / 가로 막대(항목별 합계, 큰 순) /
    원·도넛(항목별 비율, 합계가 0보다 큰 항목만)
    고른 종류는 이 PC에 기억됩니다.

  ■ 업데이트 ([설정] → [업데이트])
    켤 때 새 버전이 있으면 업데이트 내용을 보여 주고 "업데이트하시겠습니까?"를 묻습니다.
      예   → 내려받기 → "지금 설치할까요?" → 예 → 설치 후 다시 열림
             (윈도우 설치판: 프로그램이 닫혔다가 다시 열림 / 리눅스 deb·rpm: 관리자 암호 창)
      아니요 → 설정 → 업데이트에서 언제든 직접 확인·내려받기·설치 가능
    [설정] → [업데이트]: 켤 때 자동 확인 켜기·끄기, [업데이트 확인], [새 버전 내려받기],
                         [내려받은 새 버전 설치]
    - GitHub 의 공개 릴리스 목록만 읽습니다. 가계부 자료는 보내지 않습니다.
    - 윈도우 휴대용 zip 은 자동 설치가 안 되어 내려받기 페이지를 엽니다.

  ■ 백업 ([설정] → [암호 · 백업])
    지금 백업하기        : 백업 폴더에 날짜별로
    다른 곳에 저장…      : 저장할 폴더를 직접 고르기 (USB·구글 드라이브 폴더 등)
    구글 드라이브에 저장 : PC용 Google Drive 앱의 드라이브 폴더(보통 G:\내 드라이브)에
    카톡·디스코드로 보내기: 백업 파일을 복사해 두고 폴더를 엶 → 대화창에 붙여넣기(Ctrl+V) 또는 끌어다 놓기
    백업 파일로 복원하기… / 구글 드라이브에서 복원… : 고른 백업으로 지금 자료를 바꿈 (지금 자료는 따로 보관)

  ■ 표 보기 (1.6.1 — 결산 보고서·가계부·검색·자산·예약 표)
    - 금액이 칸 끝에 붙지 않게 칸 양옆과 줄 높이를 넉넉히 했습니다 (글자 크기를 바꾸면 줄 높이도 따라감).
    - 결산 보고서: 표가 화면 폭을 다 채우고(금액 칸이 남는 폭을 나눠 가짐), 0 원은 흐린 회색,
      대분류 칸은 옅은 색, 대분류가 끝나는 소계 줄 아래와 합계 줄들 위에 굵은 선.
    - 고른 줄이 옅은 색이면 수입·지출 글자색이 그대로 보입니다.
    - 표 색은 미니홈피 색으로 통일: 미니홈피·미니홈피 색(피드·타임라인) 테마는 하늘색 띠 머리줄,
      민트 줄무늬, 살구색 소계, 연보라 합계 (휴대폰판과 같음). 밝게·어둡게는 그 바탕에 맞춘 색.
    - 화면 전체: 흐린 글자·안 보이던 입력칸 테두리를 진하게, 잘리던 날짜 칸·그래프 단추·고칠 때의
      입력 칸을 바로잡음. 미니홈피 테마의 수입·지출 글자색은 파랑·분홍빨강으로 통일.
      내역을 골라 고칠 때 저장 단추 이름은 '수정 (F5)'.

  ■ 빨라진 점 (1.6.1)
    켜기 3초 → 0.5초 정도 (화면은 처음 열 때 만듦). 처음 여는 화면은 조금(0.1~0.3초) 늦게 뜰 수 있습니다.
    글꼴은 줄인 파일로 들어 있어 처음 쓸 때 한 번 풀어 사용자 캐시 폴더에 둡니다
    (리눅스 ~/.cache/gagyebu-linux/fonts). 지워도 다음에 다시 만들어집니다.

  ■ 장부 여러 개
    맨 위 '장부:' 목록에서 고르고, [설정] → [장부 관리]에서 만들기·복사·지우기
    기본 장부: 가계부 장부 + 생활비 / 용돈 / 비상금 / 여행 장부 (계정과목은 같고 내역은 빈 장부)
      - 1.5.0에서 처음 열 때 한 번만 만듭니다. 지운 장부는 다시 생기지 않습니다.
    새 장부: '장부:' 목록 맨 아래 [＋ 새 장부 만들기…] → 이름과 만드는 방법
             (빈 장부 / 지금 장부의 계정과목만 복사 / 통째로 복사) → 바로 그 장부로
             [장부 관리…] 를 고르면 [설정] → [장부 관리]가 열립니다.

8. 자주 묻는 문제
----------------------------------------------------------------------
  Q. "우리집 가계부가 이미 실행 중입니다"가 나와요.
  A. 같은 데이터를 두 창에서 동시에 쓰지 않도록 막은 것입니다.
     이미 열린 창을 쓰세요. (작업 표시줄 확인)

  Q. 도트 글씨가 작거나 흐릿해요. (화면 배율 125%·150% 등)
  A. [설정] → [화면 꾸미기] → 글꼴을 '시스템 글꼴'로. 글자 크기를 1px씩 키워도 됩니다.

  Q. 꾸민 화면 말고 예전처럼 단순한 화면이 좋아요.
  A. [설정] → [화면 꾸미기] → 테마를 '기본'으로.

  Q. (윈도우) 백신 프로그램이 실행을 막아요.
  A. 서명하지 않은 개인용 프로그램이라 그럴 수 있습니다. 직접 받은
     설치 파일이 맞다면 백신의 '예외(허용)'에 설치 폴더를 추가하세요.

  Q. (윈도우) 자료 가져오기에서 "자료 읽기 도구가 없습니다"가 나와요.
  A. 설치 폴더의 tools\mdbtools 가 지워진 것입니다. 다시 설치하세요.

  Q. (리눅스) 확인/취소 단추가 영어로 나와요.
  A. sudo apt install qt6-translations-l10n

  Q. 켤 때마다 지난 날짜 예약을 입력할지 물어봐요.
  A. 이번 달 이전 것은 기본으로 체크하지 않습니다. 필요한 것만 체크해
     입력하고, 필요 없는 것은 체크한 뒤 [체크한 것 건너뛰기(입력 안 함)]을
     누르면 다시 묻지 않습니다.
